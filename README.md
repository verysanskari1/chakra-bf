# Hiring a Boyfriend — Chakra one-pager

A single-file landing page linked from the "Hiring a Boyfriend (via Chakra)" video.

- **`index.html`** — the whole page. No build step, no dependencies. Open it in a
  browser or drop it on any static host (GitHub Pages, Netlify, Vercel, S3, …).

## Sections

1. **Hero** — "Hiring a Boyfriend" with the primary **Apply to be a boyfriend** button,
   which opens the Chakra AI interview.
2. **The Job Description** — the Rizzource Management Pvt. Ltd. posting (requirements,
   green/red flags, CTC, FAQs), ending in a second apply button.
3. **Powered by Chakra** — what Chakra is (multi-modal AI interviews, whiteboard, code
   editor, any role) with a **Try Chakra** button → https://chakra.sh

## Font: Klice

The page is set in **Klice**. Drop the font files into a `fonts/` folder next to
`index.html` and they'll load automatically:

```
fonts/Klice.woff2   (preferred)
fonts/Klice.woff
fonts/Klice.otf     (or .ttf)
```

Until the font is added, a neutral serif fallback is used so the page stays readable.
